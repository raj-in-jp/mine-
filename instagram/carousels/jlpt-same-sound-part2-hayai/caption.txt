早い or 速い? Both are read はやい, and the JLPT only accepts one 👀

早い: early, about time
速い: fast, about speed

The trick: ask WHEN or HOW FAST. When it happens is 早い. How fast it moves is 速い.

Fun fact: both have the same opposite, 遅い (late and slow).
Bonus on slide 6: 早口 (talking fast) is about speed but uses 早. Learn it as one word.

If you're learning kanji for the JLPT, same-reading kanji like these show up in the vocabulary section.
