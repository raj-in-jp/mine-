# Working rules for @raj_in_jp

Owner: Raj, Japanese-learning Instagram account @raj_in_jp (Indian, living in Japan,
faceless content, English captions). Free study site: raj-in-jp.github.io.

## 1. On every request: plan with the skills first

Before answering or building anything, pick the skills in `.claude/skills/` that fit
the request, load them, and show a short plan (which skills, why, steps). Then do it.

| Request is about | Skills to use |
|---|---|
| Reel idea or script | `ig-viral`, `ig-hook-extractor`, `ig-reel`, `marketing-ideas`, `marketing-psychology` |
| Carousel | `ig-carousel` / `ig-carousel-planner`, `copywriting` |
| Caption, hashtags | `ig-caption` / `ig-caption-writer`, `ig-hashtag-strategist`, `ig-human` |
| Weekly plan, what to post | `ig-plan` / `ig-content-planner`, `content-strategy`, `social` |
| Why reach is low, past posts | `ig-audit`, `ig-audience-insights`, `analytics` |
| Profile, bio, highlights | `ig-profile` / `ig-profile-optimizer` |
| Comments, DMs, collabs | `ig-reply`, `ig-comment`, `ig-dm`, `influencer-marketing`, `co-marketing` |
| Video / animation build | `video`, `remotion-*`, `remocn*`, `anidoodle`, `manim*`, `huashu-art-motion`, `claude-animation-base` |
| Fonts for any render | `reel-fonts` (install first) |
| Website / free PDFs growth | `lead-magnets`, `free-tools`, `seo-audit`, `copywriting` |
| Any text that goes out | finish with `ig-human` (remove AI tells) |

## 2. Credits: never without permission

Never run anything that spends credits (ElevenLabs voice/video, Higgsfield, Fish Audio,
Canva, Apify, paid APIs) unless Raj says yes for that specific job. Ask first with the
tool and estimated cost. Free work (scripts, HTML animation, editing Raj's own clips,
covers, carousels, rendering) needs no permission.

## 3. Account rules (from past feedback)

- Never use comment-keyword-to-DM CTAs (a past account was banned). Use "link in bio".
- Raj's voice (ElevenLabs "Raj") stays the main sound; music and SFX sit under it.
- Keep reels under 1 minute unless asked. Check facts before stating them.
- No personal certificates or private images in content.
- Organic hits are big "why/how" questions about Japanese as a whole; single-kanji
  tricks plateau around 3K plays.
